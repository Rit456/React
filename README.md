# React

Array Rendering 

In React, components can be reused multiple times with different data. 
It is similar to a school identity card where the card design remains the same for every 
student, but the student's details are different. 
Similarly, we use array data (a collection of objects) and render them into the same 
component so that the UI structure stays the same while the content changes dynamically.”  
“In React, we can render arrays in multiple ways. We can manually write repeated JSX, but 
the standard and most efficient approach is using the map() method. It allows us to 
dynamically render components from array data, making the code cleaner, reusable, and 
scalable.”
